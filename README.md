# Agentic DNS Intelligence Pipeline

An agentic DNS threat-intelligence pipeline that analyzes domain indicators,
enriches them with multiple intelligence sources, and generates automated
analytical reports using LLM-based reasoning.

## Overview

The pipeline ingests a domain indicator, queries multiple threat-intelligence
APIs in parallel, merges and normalizes the results, applies LLM-based
contextual reasoning to assess risk, and produces a structured HTML report.

Orchestration is handled entirely in n8n, with lightweight JavaScript logic
for normalization and report rendering.

## Pipeline Stages

1. **Indicator Ingestion** - accepts a domain via webhook, validates and normalizes it for downstream processing
2. **Enrichment** - queries VirusTotal, AlienVault OTX, and WhoIsFreaks in parallel
3. **Threat Intelligence Correlation** - merges and consolidates enrichment data into a single normalized structure
4. **Contextual Reasoning** - LLM evaluates the enriched data and produces a risk level, suspicion percentage, behavioral tags, and narrative explanation
5. **Report Synthesis** - generates an HTML report and persists it to disk

## LLM Output

For each domain the reasoning model produces:

- Risk level: `benign`, `suspicious`, or `malicious`
- Malicious suspicion percentage (weighted, not raw engine vote ratio)
- Behavioral tags (e.g. `dga`, `typosquat`, `phishing`, `c2`)
- Inferred actor (when evidence supports attribution)
- Narrative explanation suitable for a SOC analyst

## Requirements

- A running n8n instance (local or hosted)
- API keys for VirusTotal, AlienVault OTX, and WhoIsFreaks
- Access to an LLM service for contextual reasoning
- File system write access for report persistence

API keys and credentials are intentionally excluded from this repository
and must be configured through the n8n environment.

## Notes

- The n8n workflow JSON in `config/` is the authoritative execution definition
- The JavaScript files in `code/` mirror the logic inside the n8n Code nodes verbatim, included here for transparency and reviewability
- The `results/sample_reports/` directory contains representative HTML reports generated by the pipeline
